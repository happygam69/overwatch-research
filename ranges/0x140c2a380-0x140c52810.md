# Pass 70 — chunks `0629`–`0638`, `.text` `0x140c2a380`–`0x140c52810`

Pass 69 ended on an entry boundary at the open `0x140c2a380` and left four watch items.
Three of them are answered here (the `0x140c29xxx` grow/free pair, the mesh-master far
stamps, the `0xde…` auth tags — see §Watch items). The range itself is **a new tier in
one sense only**: the count of function *kinds* is tiny (zero registrations, zero record
rows, 482/482 classified `other`), but the *subject* changes completely. Behind the first
address sit three previously unread subsystems:

1. **`0x140c2a380`–`0x140c3b770` — a type/class registration belt with a hashed-component
   runtime.** 29 functions of exactly 1577 B each (the `size census: 297x29` row is that
   template) plus a 0x408-B aggregate that owns 76 named slots. Each 1577-B body allocates
   a 0x30-B descriptor (`FUN_141baff30(0x30)`), decrypts **two** in-place XOR-8 pages, and
   calls `FUN_141c4b050(&slot, &name, 0x14, size, 0, align)` — one descriptor per class.
   The name pages in this range's pool block are `'Unknown'` placeholders, so the *class*
   names are unrecoverable here (Corrections 57 class), but the **type tag byte** each body
   stores at `descriptor+8` is readable: `0x1a 0x1b 0x1c 0x1d 0x1f 0x2d 0x3e 0x4d 0x54 0x55
   0x56 0x59 0x5f 0x60 0x64 0x67 0x68 0x69 0x6f 0x75 0x76 0x77 0x7a 0x85 0x8b 0x8d 0x93
   0x9e 0x9f 0xa4 0xa5 0xa6 0xaa 0xb4`.
2. **`0x140c36c10`–`0x140c395a0` — the AI avoidance-goal tier.** The band's name pages are
   the only ones in the whole range that decode to real text: **`'Distance Constraint'`
   `0x1438720B8` (len 0x13), `'Avoid Spawn Blockers'` `0x1438720D8` (0x14), `'Goal LOS To
   Target'` `0x143872100` (0x12), `'Goal Traveled Distance'` `0x143872120`,
   `'Goal Avoid Hazards'` `0x143872148`, `'No Failure'` `0x143872168`/`0x143872180`,
   `'Sphere Dir'` `0x1438721C8`**, plus the downstream `'Sampler Point List'`
   `0x143872608`, `'Goal Dist Envelope'` `0x143872628`, `'AIStuckMonitoringPathFinderWorkPool'`
   `0x143872648` and the seven `'Invalid Entity Position'` pages `0x143872678`–`0x143872768`.
   Registration is table-driven (no literal `&DAT_` for any of them: `crossref.py` on the
   base and on base+0xC both return 0 chunks), so the *owner* is the belt, the *semantics*
   are the strings.
3. **`0x140c43930`–`0x140c52810` — a per-frame "CFPS" capture/playback track.** Four ASCII
   log lines are the naming evidence: `"CFPS: Unable to load input capture %s with error
   %i. \n"`, `"CFPS: Input capture %s is empty file. \n"`, `"CFPS: Input capture %s is
   corrupted, playback might be compromised:\n"`, `"CFPS: frame %i, id %i, hero %i, team
   %i \n"` (`FUN_140c445f0`). The file header is 0x18 B, the frame rows are **0x58 B**,
   playback objects are **0x560 B**, and the stream decodes through the pass-31 arithmetic
   reader (`FUN_141af00a0` / `FUN_141af0340`).

Around them the usual engine furniture: five 1577-B-shaped hashed containers with the
**fifth hash family** (`(x*0x40000+~x)*0x15*0x41`, ledgers 62/88), a **0x1b0-B avoidance
agent** with eleven 99.0f goal weights, an **open-addressing component registry with
listener fan-out**, a **spatial hash partition with AABB range queries**, and seven
giants that are window hosts.
