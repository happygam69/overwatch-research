# Pass 67 — chunks `0603`–`0611`, `.text` `0x140bb5e90`–`0x140bda720`

The watch item from pass 66 named one thing at chunk 0603: the Battle.net
lobby/gateway connection manager. It is there, but it is not the front of the
range — the first five chunks are the **client view/camera render-object belt**
(the family that pass 59's view/camera state engine drives, at last readable as
class instances), and the lobby manager turns out to be the *outer shell* of a
much bigger thing: a **33-state Battle.net web-authentication tower**
(`0x140bc86f0`–`0x140bda720`) with its own HTTP job template, header/cookie
builders, JSON writers/parsers and a gate-service transport that caps at **8
in-flight requests**.

Two tables make the pass: `0x14386dc30` is the **33-entry state-name pointer
table** for `AuthenticationSystem` and `0x14386db70` is the per-state
**timeout-error-id table**, both read out of the image with `dumpva.py`. With
them the whole state machine decodes — every `state == N` test in the range now
has a name, and the `strscan` page names stop being anonymous error strings and
become per-state transitions. That is the milestone: the auth tier is closed.

Zero registrations, zero records: **67 consecutive consumer-only passes**. 209
functions for 1,019,554 B of post-strip text.
